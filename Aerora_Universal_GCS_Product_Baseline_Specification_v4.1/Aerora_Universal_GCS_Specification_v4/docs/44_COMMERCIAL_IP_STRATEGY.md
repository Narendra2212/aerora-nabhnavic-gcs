# 44 — Commercial IP Strategy

## IP layers

### Third-party
QGC, Qt and other dependencies retain their applicable rights/licenses.

### Aerora-owned
Original Aerora:
- UI designs/code
- domain modules
- proprietary algorithms
- payload integration
- mission logic
- AI application code/models where ownership permits
- documentation created by Aerora
- brand/trademarks

Ownership depends on actual authorship, contracts and applicable law.

## Product boundary

Do not claim ownership of third-party code merely because it is incorporated into the product.

## Commercial readiness

Before distribution:
- dependency/license audit
- legal review
- trademark review
- customer contract/IP review
- source/notice obligations review
- export/control review where applicable

This document is not legal advice.


## Product baseline cross-reference

This document shall be interpreted against `docs/46_PRODUCT_BASELINE_ANALYSIS.md`, which records the uploaded FC schematic, PCB and Simulink evidence. Where the uploaded firmware model contains a `PLACEHOLDER`, `PENDING`, or `NOT YET INTEGRATED` statement, this specification treats the item as unresolved engineering work rather than a verified capability.
